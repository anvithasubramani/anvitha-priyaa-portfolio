MSc DISSERTATION · QUEEN MARY UNIVERSITY OF LONDON

Collaborative Multi-Agent Large Language Model Architectures for Long-Context Code Analysis

The study compared five LLM architectures across bug detection, code optimisation, code summarisation and long-context reasoning. The aim was to understand how architectural choices influenced response quality and computational overhead.

5 Architectures compared
4 Code-analysis tasks
100 Benchmark evaluations
